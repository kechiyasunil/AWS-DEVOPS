# AWS and DevOps Documentation

This repository contains various PDF documentation related to **AWS** and **DevOps** technologies. The documents are organized into two main categories: AWS-related projects and DevOps-related practices.

## Contents

### AWS Documentation
The **AWS-pdf** folder contains PDFs covering various topics and mini-projects that utilize AWS services. These documents serve as guides and tutorials for working with the following AWS components:

- **Auto Scaling Groups and Load Balancers**
- **CloudFront (CDN)**
- **Cost Optimization (Using Lambda Functions to Remove Stale Resources)**
- **DynamoDB**
- **Elastic IP**
- **EBS Volumes and Snapshots**
- **IAM Roles and Users**
- **RDS**
- **VPC and NAT Gateways**
- **VPC Peering**
- **CloudFormation for VPC**
- **CloudWatch Metrics and Notifications**

### DevOps Documentation
The **DevOps-pdf** folder includes PDFs covering key concepts, tools, and practices in the **DevOps** lifecycle, such as automation, integration, and continuous delivery. These documents include tutorials, guides, and mini-projects involving the following tools:

- **Ansible**
  - Master and Slave Concepts
  - Ad-Hoc Commands
  - YAML Data Types
- **Docker**
  - Docker Basics
  - Docker Networking
  - Docker Hub
  - Dockerfile
- **Git**
  - Git Basics and Commands
  - Git in DevOps Workflows
- **Jenkins**
  - Building Projects with Maven in Jenkins
  - SCM Integration and GitHub
  - Jenkins Webhooks and Pipelines
  - Parameterized Builds
  - Email Notifications
  - Upstream and Downstream Jobs
  - Java and Maven Configuration in Jenkins
  - Jenkins Plugins
